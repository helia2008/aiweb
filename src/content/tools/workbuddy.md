WorkBuddy 是把"桌面 Agent 工程师能做的事"装进一个图形界面的工作台。对非程序员最友好的一条路，也是我自己主力在用的。

**强在哪**：能直接挂在你电脑的文件上、能跑定时任务、能连第三方的服务和数据源（飞书、企微、Notion、Excel、本地文件夹），不需要你写一行代码。
**弱在哪**：相比直接调 API 的 Claude Code 灵活度低一点；遇到非常规的数据结构，可能需要手动写一次配置。
