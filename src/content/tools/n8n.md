  - 跨系统的每日重复流程

  - 对命令行和 Docker 完全陌生

把"收邮件 → 提信息 → 写表格 → 发通知"整条链路画出来，之后每天自己跑。前期投入大，回报是永久的。

**强在哪**：可视化编排工作流；上百个内置节点（HTTP、数据库、IMAP、Slack、飞书、企业微信……）；能定时、能被事件触发、能加判断分支。
**弱在哪**：单次任务的"智能"不如 Claude Code 强——你得自己把流程拆得足够细；对非程序员仍有 Docker 安装这一关要过。
