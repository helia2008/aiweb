## 这个活到底烦在哪

真正的麻烦不是"合并表格"这一步，而是它前面的一堆脏活：文件名没有统一规则、同一个店有时叫"一店"有时叫"01 店"、有人发 PDF 有人发照片、还有两张发票是同一笔重复提交。这些事 Excel 帮不了你，规则再多也堵不住人的随意性。

所以要交给 Agent 的不是"合并"，而是"先读懂，再判断，再整理"。这也是它能做、而宏和公式做不到的地方。

## 要准备什么

一个装好桌面 Agent 的电脑、一个固定的发票存放文件夹（按月分，例如 `/财务/2026-08`）、以及一份你手动做过一次的成品表格作为样板。

> 样板很重要——你不给它看成品长什么样，它就会自由发挥。

## 一步步怎么配

1. **先跑一次手动流程**。把八月的发票像往常一样人肉合并一遍，把成品表存为 `样板-2026-07.xlsx`。
2. **把 Agent 指向这个文件夹**。让它读 `样板-2026-07.xlsx`，自己推断列结构和门店命名规则。
3. **第一版指令先发"只读"任务**。让它先输出"我看到这些字段、这些门店"对一遍，确认它读懂了，再让它做合并。
4. **第二版才发合并指令**。指令里明确写"不动原文件，结果另存为"。
5. **每条规则都加例外**。比如"门店名归一"附一个"但如果店名里带'临时'两个字就保留原名"。

## 直接能抄的指令

```text
把「财务/2026-08」里所有发票读一遍，门店名按下表归一：
一店 = 01店 = 门店1，二店 = 02店 = 门店2，依次类推。
输出一张表，列为：门店、日期、金额、发票号、备注。
同一门店、同一金额、同一日期出现两次的行，在备注写「疑似重复」并标红。
不要改动任何原文件，结果另存为「报销汇总-2026-08.xlsx」。
```

## 我踩过的三个坑

1. **它会把两家名字相近的店归成一个**。我第一次直接交上去，被财务退回——"一店"和"一分店"其实是两家店。加了"店名带'分'字不归一"这一句才解决。
2. **金额单位混用**。有的发票是"人民币"，有的是"元"，有的是"¥"。我加了一句"金额统一为阿拉伯数字、不带单位"。
3. **它自作主张改了表头**。我让它"按样板的表头"，但它自己认为"加一列备注更清楚"——这正是不能让它"自由发挥"的典型场景。现在所有指令第一句都写"严格按样板的列名，不增不减"。

跑完先别急着交。抽查五张发票对一遍金额和门店，确认无误再放进流程。
