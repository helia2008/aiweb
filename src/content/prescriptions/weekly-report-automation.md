## 这个活烦在哪

不是写本身，是"记"。周一开了三个会、周三改了两版方案、周四和客户吵了一架——等你周五下午要写周报时，能想起一半就不错了。所以"周报"难的不是行文，是回忆。

## 怎么交给 Agent

不是让它"帮你写周报"——这是空话。它没法知道你这周做了什么。
是让它做三件具体的事：
1. **从来源里抓你这一周做过什么**（聊天记录、工单系统、邮件、文档历史）
2. **按你给的模板拼成草稿**
3. **把不确定的、可能敏感的标出来**让你确认

## 要准备什么

- 一份周报模板（标题、进展、问题、下周计划、需要的支持）
- 数据来源清单：企业微信/钉钉/飞书的导出文件夹、邮箱 PST、工单系统的 CSV、Notion/语雀/Confluence 的周文档列表

## 一步步怎么配

1. **先让 Agent 列出它能从每个来源抓什么**。比如"企业微信：和 12 个群有对话；邮件：本周收到 47 封；工单：处理了 8 个"。**你确认它覆盖到你的真实工作面**，再继续。
2. **给它一份上周的周报当样板**。让它学你的行文风格、用词偏好。
3. **第一版跑出来只读不改**。你只做一件事：判断它"抓得对不对"——有没有漏的、错的、敏感的。**不要在它没抓对之前去改文字。**
4. **改两版**。把"该抓的没抓"、"不该抓的抓了"都圈出来，喂回指令里迭代。
5. **跑稳后每周固定时间跑一次**。建议周五下午 3 点，留 2 小时你润色。

## 直接能抄的指令

```text
按 sources.yaml 列的来源扫我这周留下的痕迹：

- 企业微信导出：/weekly/wechat/2026-W34/
- 邮件：/weekly/mail/2026-W34.mbox
- 工单：/weekly/jira/2026-W34.csv
- 我的文档：/weekly/docs/2026-W34/

输出三件事：
1) 本周做过的事，按"项目 > 关键动作 > 涉及人"列出。
2) 遇到的问题 / 卡点 / 风险。
3) 我提过但还没回的事。

每条标来源（"这条来自企业微信-产品群，8/23"）。
涉及客户名、人名时一律打码成「XX 公司 / XX 同事」。
只产出草稿，不要写到我的正式周报文档。
```

## 我踩过的坑

1. **它把不该引用的也引了**。第一版里出现了客户公司全名、合同金额。**解法**：在指令里强制"涉及客户名、人名时一律打码"。
2. **它自己加观点**。"本周进展顺利"——这是它加的，我没说。**解法**：加一句"只复述事实，不评价"。
3. **"下周计划"完全靠猜**。Agent 不知道你下周要做什么。**解法**：周报里"下周计划"那一栏留空，你周五下班前 5 分钟手填，比让 Agent 猜准得多。

## 何时不要用

如果你这周主要在做**调研、思考、谈判**这类"动作少、密度高"的事，Agent 抓不到什么——你周报本来也得靠回忆。这种时候别勉强自动化，把时间省下来写反思笔记更值。
