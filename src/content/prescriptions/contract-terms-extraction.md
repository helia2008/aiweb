## 这个活烦在哪

每到月底或者季度盘点，法务和采购总要被问一句"XX 合同快到期了吗"。答案散在每个供应商的 PDF 里，要找得一份份打开。一个月一两百份合同，挨个查至少两个工作日。

## 要准备什么

- 一个空的汇总模板表，至少包含：合同名、对方主体、签约日期、到期日、付款方式、违约金比例、争议解决地
- 一个 `contracts/` 文件夹，按"对方主体-年-月.pdf"命名（命名越规整，Agent 出错率越低）
- 桌面 Agent 选 WorkBuddy 或 Claude Code，二者在这个任务上差异不大

## 一步步怎么配

1. 先让 Agent 跑一份**小样本**（3 份合同），把抓出的字段打印出来对一遍。
2. 字段名你定。让它读你的模板表，按你给的列名抓信息。
3. **强制要求出处页码**。每一条抓出来的字段后面，跟一个 `（来自第 N 页）`。这一步是命根子——不抽查直接用，是要出事的。
4. 跑全量。结果另存为 `合同汇总-2026-Q3.xlsx`，不要覆盖原文件。
5. 跑完**抽 5 份人工复核**，重点看金额、日期、对方主体这三个最容易错的字段。

## 直接能抄的指令

```text
读「contracts/」下所有 PDF。按下面这张表（模板见附件）抓字段：
合同名 / 对方主体 / 签约日期 / 到期日 / 付款方式 / 违约金比例 / 争议解决地。

每一条字段后面必须标注它来自第几页，例如：
签约日期：2025-03-12（第 2 页）。

如果某份合同没找到某字段，写「未找到」而不是猜。

结果另存为「合同汇总-2026-Q3.xlsx」。不要改动原文件。
```

## 我踩过的坑

1. **签约日期和生效日期不是一回事**。有些合同"自双方签字之日起生效"，有些写"自 XX 日起生效"。我让 Agent 抓"生效日"就出现两份不同答案——后来改成"页面里第一次出现的日期 + 字段名"，问题就稳定了。
2. **对方主体写简称还是全称**。同一家公司在不同合同里有时叫"北京 X 科技有限公司"有时叫"X 科技"。加了一条"以营业执照登记名为准"才稳。
3. **扫描件 PDF 抓不出来**。这是死结——扫描件本质是图，Agent 读不准。遇到扫描件你只能要么人工补、要么先用 OCR 工具过一遍。

## 回本估算

按 200 份合同、人肉 2 个工作日算，单次回本。如果你公司一年过 2000 份合同，这条路可以交给一位实习生维护，AI 跑、她只负责抽查。
