# 社区分发素材包（第 1 阶段 · 攒流量）

> 用法：每周挑 1 篇处方，从对应平台的模板改一版发出。发布后把链接回填到对应处方的相关位（内链）。
> 通则：**只带一个链接**（处方详情页）；开头 3 秒讲痛点不讲工具；评论区有人问就贴踩坑细节，别贴链接刷屏。

## 即刻（AI 登陆派 / 一起做产品等圈子）

**模板**：痛点一句 → 我怎么做的一句话 → 结果数字 → 「完整步骤和可抄指令放 blog 了」+ 链接

示例（配 weekly-report-automation）：
> 每周日晚被周报折磨的第 N 周，我终于受不了了。
> 现在我的做法：三个项目的 Excel + 飞书群聊天记录直接丢给桌面 Agent，说一句人话，8 分钟出一份结构完整的周报初稿，我只通读改两处。
> 不是 ai 生成的水话——过滤闲聊、按项目分组、800 字以内，都是指令里写死的。
> 把完整步骤和可直接抄的指令写成了教程（含我踩的 3 个坑）：https://aiwind.eu.cc/prescriptions/weekly-report-automation

## V2EX（/go/ai 或 /go/programmer）

**框架**：标题用场景不用营销词 → 正文讲「前后对比 + 关键指令 + 翻车记录」→ 结尾轻带链接

标题示例：`分享：不写代码，把每周日 2 小时的周报压到 20 分钟的完整流程`

正文要点（用 weekly-report-automation 内容改写）：
1. Before：40 分钟手工拼（贴原始流程）
2. 关键指令原文贴 2 段（站里「直接能抄指令」章节现成）
3. 踩坑：合并单元格会让解析错位 / 数据敏感的处理口径
4. 结尾：「完整版在我自己的小站（非营销号，个人实测记录）：链接」

## 小红书

**框架**：封面图用「前后时间对比」大字 → 正文 emoji 分步 → 标签带搜索词

标题示例：`周报 2 小时→20 分钟｜不用代码的 AI 周报流程📝`
正文要点：分 3 步截图式描述（丢文件→说要求→检查导出）；踩坑单独列一节「⚠️我翻的车」；标签：`#ai办公 #周报 #职场效率 #打工人 #excel`

## 首发节奏建议（前 4 周）

| 周 | 处方 | 首发 | 理由 |
|---|---|---|---|
| W1 | weekly-report-automation | 即刻 + V2EX | 受众最广、搜索词最热 |
| W2 | resume-screening-pipeline | 小红书 | HR/职场人群聚集 |
| W3 | supplier-statement-reconciliation | V2EX | 财务痛点硬核向 |
| W4 | list-diff-pipeline | 即刻 | 轻量、互动率高 |

## 效果回收

- 每帖发出 72h 后记录：即刻/小红书看站内分享数据，V2EX 看回复
- 站内效果等 GSC 上线后看 direct/ referral 流量（CF Web Analytics 有 referrer 报表）
- 哪个平台带来留存（二次访问）就加码哪个，数据说话
